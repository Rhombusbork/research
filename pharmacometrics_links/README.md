# 정량약리학 식 연결하기

목표: 지난 수업(pharmacometrics_1h)의 식들을 이미 아는 개념에 연결하고, 두 개의 뿌리 식으로 압축해 체화한다.
수업 방식은 ../pharmacometrics_1h/tutor_prompt.md를 따르되, 시간 제한은 없다.

## 핵심 아이디어

정량약리학의 식은 두 뿌리에서 나온다.

| 뿌리 | 형태 | 이미 아는 개념 | 여기서 나오는 식 |
|---|---|---|---|
| 1. 들어온 만큼 나간다 | dX/dt = 들어옴 − k·X | 1차 반응 속도론, 방사성 붕괴, ln2 | 지수 감소, 반감기, AUC, 정상상태, 간접 반응 |
| 2. 자리가 정해져 있다 | 속도 = 최대 · S / (K + S) | 미카엘리스-멘텐, 화학 평형, 랭뮤어 흡착 | Emax 모델, 수용체 점유, 비선형 약동학 |

## 블록

| 블록 | 연결 | 적용 문제 |
|---|---|---|
| 0 | 진단: 이미 편한 개념 확인 | 없음 |
| 1 | 1차 반응 속도론 → C(t), 반감기 | 반감기 3번이 지나면 몇 % 남나? |
| 2 | 미분방정식 하나로 블록 1·2·4 통일 | 간접 반응 식에서 정상상태 식을 유도하기 |
| 3 | 미카엘리스-멘텐 = Emax | Km과 EC50, Vmax와 Emax 대응시키기 |
| 4 | 두 뿌리의 충돌: 비선형 약동학 | 페니토인 용량을 조금 올렸는데 농도가 폭등하는 이유 |
| 5 | 지수와 로그: 개인차와 체중 법칙 | 왜 개인차를 e^η로, 체중을 0.75제곱으로 쓰나 |
| 6 | 통합 적용: 처음 보는 약 하나를 두 뿌리로 분석 | 주어진 자료로 용량 설계 |
| 7 | 인출: 두 뿌리 식만 보고 나머지 식을 다시 유도 | 없음 |

각 블록의 리듬: 아는 개념 떠올리기 → 대응시키기 → 처음 보는 문제에 적용 → 연결 문장 하나로 압축.

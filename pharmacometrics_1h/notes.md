# 정량약리학 1시간 핵심: 내 노트

## 내가 쓴 원리 여섯 개

1. 질량 보존과 청소율: 총 노출량(AUC = 용량/청소율)은 청소율이 정하고, 분포 용적은 곡선의 모양(높이와 반감기)만 바꾼다.
2. 반복 투여와 정상상태: 정상상태의 높이는 투여 속도를 청소율로 나눈 값이고, 도달 시간은 반감기만이 정한다(약 4~5 반감기). 용량을 올리면 높이만 바뀐다. 시간을 줄이려면 부하 용량으로 높이를 미리 채운다.
3. 농도-효과 관계: 수용체 수가 정해져 있어 효과는 농도 초기에 가장 가파르게 늘고 점점 완만해지다 최대효과에서 멈춘다. 그래서 용량을 올려 얻는 효과는 현재 농도가 EC50의 어디에 있느냐가 정한다. (원래 곡선은 쌍곡선, S자는 로그 축 때문)
4. 시간 지연과 회전율: 생성을 바꾸는 약의 효과는 약의 농도가 아니라 매개체의 회전 속도를 따라간다. 매개체 반감기가 길수록 효과는 늦게 오고, 단회 투여에서는 덜 깊다. 계속 투여하면 깊이는 같아지고 속도만 다르다. (와파린의 지연)
5. 변동성의 구조: 흩어짐을 사람 사이의 차이(η)와 측정 잡음(ε)으로 나눠 함께 추정하면, 한 사람당 채혈이 적어도 집단의 전형값과 개인차를 알 수 있다. 그래서 집단을 알려면 채혈 횟수보다 사람 수가 중요하다. (나누지 않으면 잡음이 개인차로 부풀려진다)
6. 모델에서 결정으로: 청소율은 체중의 0.75제곱에 비례하므로, 목표 노출량에 예상 청소율을 곱해 용량을 계산한다. 하지만 개인차가 남기 때문에 후보 투여법을 가상 집단에 시뮬레이션해 목표 범위 안 비율을 비교하고, 그 차이가 의미 있는지는 사람이 판단한다. (니볼루맙의 고정 용량 전환)

## 블록별 핵심 식

### 블록 1 · 질량 보존과 청소율
```
C(t) = (Dose / V) · e^(−k·t),   k = CL / V
반감기 t½ = 0.693 · V / CL
AUC = Dose / CL
```
- V는 처음 농도와 반감기만 바꾼다. AUC에는 없다.
- 치워지는 양의 속도 = CL × C

### 블록 2 · 반복 투여와 정상상태
```
평균 정상상태 농도 Css,avg = (Dose / τ) / CL        τ = 투여 간격
정상상태 도달 ≈ 4~5 × t½   (용량과 무관)
부하 용량 = 목표 농도 × V
```

### 블록 3 · 농도-효과 관계
```
D + R ⇌ DR,   Kd = koff / kon
보존: Rtot = R + DR
점유율 = C / (Kd + C)
E = Emax · C / (EC50 + C)            (효과 ∝ 점유율이면 EC50 = Kd)
E = Emax · C^n / (EC50^n + C^n)      (Hill 계수 n: 곡선의 가파름)
```

### 블록 4 · 시간 지연과 회전율 (간접 반응 모델 I)
```
dR/dt = kin · (1 − C / (IC50 + C)) − kout · R
기저 수준 R0 = kin / kout
매개체 반감기 = 0.693 / kout
```
- 효과의 시간표는 약의 반감기가 아니라 kout이 정한다.

### 블록 5 · 변동성의 구조 (혼합효과 모델)
```
CLi = CLpop · e^(ηi),        ηi ~ N(0, ω²)   사람 사이의 차이
Cobs = Cpred · e^(ε),        ε ~ N(0, σ²)    측정 잡음
```

### 블록 6 · 모델에서 결정으로
```
CLi = CLpop · (WT / 70)^0.75                 체중의 0.75제곱 법칙
용량 = 목표 AUC × CLi
1회 용량 = 목표 Css,avg × CLi × τ
체중당 용량: AUC ∝ WT^0.25,   고정 용량: AUC ∝ WT^−0.75
```

## 틀렸던 예측과 그 이유

- 블록 1: 분포 용적이 두 배면 AUC가 절반이라 예측. 높이(농도 절반)만 보고 폭(시간 두 배)을 놓쳤다. 청소율은 양이 아니라 부피/시간이다.
- 블록 2: 처음엔 정상상태를 '같아지는 한 순간'으로 이해했다. 실제로는 한 투여 간격 동안 치워진 양 = 투여량이 되어 같은 톱니가 반복되는 상태다. 압축 때 시간을 청소율 탓으로 썼으나, 반감기(V와 CL)가 정한다.
- 블록 4: 반감기가 짧은 매개체 A는 효과가 없을 거라 예측. 실제로는 A가 더 빠르고 깊게 반응했다. 매개체 반감기는 '생성되는 시간'이 아니라 '사라지는 속도'다.
- 블록 6: 체중 비례 지수를 '0.75배'로 이해했다. 실제로는 0.75제곱이다(체중 두 배 → 청소율 약 1.7배).

## 최종 인출 시험 (아무것도 보지 않고 다시 쓴 것)

1. 총 노출은 청소율에 반비례하며 용적과는 관련 없다. → 정확
2. 반복 투여를 통해 정상상태에 도달할 수 있으며 이는 농도에 관계없이 청소율이 중요하다. → 부분. 도달 시간은 청소율이 아니라 반감기(V와 CL)가 정한다. 높이는 투여 속도/청소율. 블록 2 압축 때와 같은 오류가 반복됨.
3. 효과는 농도에 따라 쌍곡선 형태로 증가한다. 로그로는 시그모이드 곡선이며 EC50에서 기울기가 가장 크다. → 정확. 용량 증가의 이득이 위치에 달려 있다는 함의는 빠짐.
4. 약물의 효과는 약물 농도가 아닌 효과 매개체의 역학에 따라 일어난다. 매개체 반감기가 짧을수록 효과가 빠르고 강하다. → 정확. 블록 이름은 잊었음. '강하다'는 단회 투여에서만.
5. 개인 내 차이와 각각 개개인별 차이로 나누어 계산한다. → 부분. 개인 내 쪽은 측정 잡음(ε). '그래서 채혈보다 사람 수'라는 결론이 빠짐.
6. 대사율은 체중의 0.75제곱에 비례하며 이를 통해 적정한 투여 용량을 계산할 수 있다. → 부분. 남은 개인차 때문에 시뮬레이션과 사람의 판단이 필요하다는 절반이 빠짐.
